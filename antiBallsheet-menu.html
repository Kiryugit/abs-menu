玩法一条规则，一个秒表

只用鼠标

目标

尽可能快地接够设定数量的球。计时从第一颗球开始，接完最后一颗停止，就这一条规则。

触碰

光标悬到球上即可，不用点击。光标就是命中范围，半径与球相同， 所以粉球与光标刚好重合时就算接到。

按键

  • R / 空格 — 开始一局、重开一局
  • ESC — 局中暂停 / 菜单里返回
  • ↑↓回车 — 菜单上下选择
  • F11 — 浏览器全屏

怎么看数字

用时是整局时长，平均反应是球与球之间的平均间隔， 最快 / 最慢是两端的极端值。球数越少，一次失误的代价越大。

第二套规则 · BallSheet

菜单第 02 项是原始 ballsheet 的规则，跑在同一块 600 像素场地上：血量从 100 起， 从第一次碰到球开始按 压力 · ln(1 + t) 持续扣减——首次触碰只启动计时。 之后每次吃球回分，反应低于快球阈值时只按 r / 阈值 结算， 每秒得分是最近五秒内吃到的分数除以五。血量跌破零，本局结束。

原版说明

光标尺寸只影响观感，判定始终用球径。局中重开会丢掉这一局，接完最后一颗之前不会写入任何记录。 成绩按分类存放（球数 × 球径），换模式就是另一份记录。

关于构建与致谢

—

这是什么

antiBallsheet 是 ballsheet 的反应力速通重制版：尽快接完 N 颗球， 没有压力公式、没有画布——只有 DOM 和 transform。原版游戏、引擎与成绩系统由 dph（dphdmn）制作。

这一版在外面加了一层菜单：标题页、模式与配色面板、历史浏览、暂停与结算页。 玩法代码、命中判定、设置键名、成绩存储全部保持原样。

可选的 BallSheet 项是把 dphdmn/ballsheet（helloimxtal 的 p5 版） 的规则移植到同一块场地和同一套 HUD 上——只有血量、压力、每秒得分和快球折扣， 成绩单独存档，不会碰速通的记录。

来源

github.com/dphdmn/antiBallsheet

实现

  • 原生 JS + DOM transform，无构建步骤
  • Chart.js 画成绩曲线，random-js 负责球位
  • 记录存在 localStorage，清理浏览器数据即清空
  • 单文件，离线可用，双击就能玩
